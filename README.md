## How to Run

### HTML, CSS, and JavaScript
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open any `.html` file in a web browser.
4. Alternatively, install the Live Server extension in VS Code and launch the HTML file using Live Server.

### PHP Programs
1. Install PHP or a local server environment such as XAMPP.
2. Start Apache if you are using XAMPP.
3. Place the project folder inside the XAMPP `htdocs` directory.
4. Open the PHP file through your browser. For example:

   `http://localhost/WD/php_q1_welcome_date.php`

**Note:** PHP files must run through a PHP-enabled server; opening them directly in a browser will not execute the PHP code.
